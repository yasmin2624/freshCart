# 🛒 FreshCart – E-Commerce Web Application  

This project is my **graduation project from Route Academy** 🎓.  
It’s a full front-end **E-Commerce application** built with **React.js** and modern tools, focusing on clean architecture, responsive design, and seamless user experience.  

---

## 🚀 Tech Stack & Tools  

- **React.js** → Fast, interactive UI with component-based architecture  
- **React Hooks** → State & lifecycle management  
- **React Router DOM** → Smooth navigation & routing  
- **Tailwind CSS** → Clean, responsive, and efficient styling  
- **Formik + Yup** → Form handling & validation  
- **Axios** → API integration & HTTP requests  
- **React Spinners** → Elegant loading indicators  
- **React Hot Toast** → User-friendly notifications  
- **Vercel** → Deployment & hosting  

---

## 📂 App Structure & Core Features  

### 🔐 Authentication  
- Register / Login Pages  
- Forgot Password, Verify Reset Code & Reset Password  

### 🏠 Store Features  
- **Home Page** → Showcasing featured products  
- **Product Details** → Dynamic product info view  
- **Categories & Brands** → Filtering & browsing items  

### 🛍️ Shopping Features  
- **Cart & Wishlist** → Full CRUD functionality  
- **Checkout & Secure Online Payment Integration**  
- **All Orders Page** → View past orders
